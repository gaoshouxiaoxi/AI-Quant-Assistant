# 跨股票验证报告（Cross-Stock Validation）

> 预注册见 [preregistration_cross_stock.md](preregistration_cross_stock.md)（在抓取任何新行情之前提交，commit `079e310`）。
> 全部数字由 `python run_cross_stock.py` 生成，可用 `--gate` 验证流程一致性。

---

## 结论（一句话）

**原有误差优势能够在更广的股票样本中重现，但幅度明显小于原始 3 只股票，
且在高波动股票/区间上系统性失效；排序能力不足的问题同样重现。**

按预注册门槛判定：**支持 H1**（中位数 Skill +21.57%，95% CI [+8.25%, +27.77%]，
正 Skill 占比 84%）。

---

## 1. 样本

| 项 | 内容 |
| --- | --- |
| 股票池 | 沪深300 成分股快照 2026-10-16，共 300 只 |
| 选择规则 | 按**股票代码升序**，逐个检查数据完整性，取前 25 只 |
| 实际选中 | **25 只，零排除**（全部 1970 根 bar，区间 2024-09-30 ~ 2026-10-16） |
| 结果 | 全部落在深市主板 `000xxx`（`000001` ~ `000807`） |

**这是规则导致的成分特征，不是挑选**：沪深300 中 `000xxx` 代码的股票超过 25 只，
按升序取前 25 只自然全落在该区间。代价是样本**不含沪市 `600xxx` 与创业板 `300xxx`**，
这一点写入局限（§6）。

数据口径与主实验完全一致：60 分钟 bar、日度 RV = `Σr² + 隔夜²`、
目标 `log(未来 5 日均值 RV)`、5 折扩展窗口、purge = 5。

## 4. 预注册敏感性检验（全部四项）

| 检验 | 股票数 | 中位数 Skill | 正 Skill 占比 | 结论 |
| --- | --- | --- | --- | --- |
| 基准（全样本） | 25 | +21.57% | 84% | — |
| **剔除隔夜前 1%**（防除权污染） | 25 | +21.34% | 80% | ✅ 几乎无变化 |
| **时间前半段** | 25 | +17.15% | 80% | ✅ 稳定 |
| **时间后半段** | 25 | +19.27% | 92% | ✅ 稳定 |
| **基线改为当日 RV** | 25 | +23.17% | 84% | ✅ 不依赖基线选择 |
| 档位-低波动 | 25 | +38.23% | 88% | 偏差 **+0.51**（高估） |
| 档位-中波动 | 25 | +61.14% | 96% | 偏差 −0.15 |
| **档位-高波动** | 25 | **−10.03%** | **40%** | 偏差 **−0.84**（低估） |

**最关键的稳健性发现**：误差优势**不是均匀分布的**。它在低/中波动区间很强
（中位数 +38% / +61%），而在**高波动区间为负**（−10.03%），且只有 40% 的股票为正。

## 5. 与原始 3 只股票实验的对比

| 指标 | 原 3 只（600519/000858/000001） | 25 只 |
| --- | --- | --- |
| Skill 平均 | +28.45% | +15.78% |
| Skill 中位数 | +29.09% | +21.57% |
| 正 Skill 占比 | 100%（3/3） | 84%（21/25） |
| Spearman（模型 vs 基线） | 0.324 vs 0.387 | 0.369 vs 0.392 |
| 模型排序更优的股票 | 0/3 | 9/25 |

**原 3 只样本高估了效应**（+28.45% → 均值 +15.78%）。原因有两个，都值得记录：

1. **标的集中**：茅台与五粮液同属白酒，走势高度相关，
   3 只股票的有效独立样本接近 2，不是 3。
2. **区间与个例效应**：`000725 京东方A`（−32.69%）与 `000657 中钨高新`（−12.09%）
   这类高波动股票在 3 只样本中完全缺失。

**这正是扩样本的价值：它把 +28% 修正为 +21.57%（中位数），并揭示了失效区域。**

## 6. 局限（事先承认 + 事后补充）

| 局限 | 说明 |
| --- | --- |
| **全部为深市主板 `000xxx`** | 预注册规则（代码升序取前 25）的机械后果，未覆盖沪市与创业板。跨交易所推广需另做分层抽样。 |
| **单一时间区间** | 2024-10 ~ 2026-10，仍是一个市场环境；"时间稳定性"只验证了该区间内的前后半段。 |
| **分钟线不复权** | 除权日产生假跳跃。已做"剔除隔夜前 1%"敏感性检验（+21.34%，几乎无变化），但不能完全消除。 |
| **单股推断很弱** | **25 只中有 15 只的单股 95% CI 包含 0**。能下结论的是"跨股票中位数为正"，不能对单只股票说"该模型有效"。 |
| **未做多重比较校正** | 25 次单股检验未校正。若按 Bonferroni，几乎没有单只股票能显著。 |
| **只测了 HAR-3** | 多因子与其他基线不在本次范围（预注册即如此）。 |

## 7. 这个结果改变了什么

| 原结论（3 只） | 现在（25 只） |
| --- | --- |
| 误差优势 +28.45% | 中位数 +21.57%，均值 +15.78% —— **成立但更小** |
| 三只全部为正 | 84% 为正，4 只显著为负 |
| 排序不如基线 | **同样成立**（9/25 更优，中位差 −0.025） |
| 强收缩（离散度 0.35） | **同样成立**（中位 0.51，仍有强收缩） |
| 低波动高估、高波动低估 | **同样成立，且更明确**（+0.51 / −0.84） |
| — | **新增**：高波动区间 Skill 中位数为负（−10.03%） |

**没有改变的**：HAR 仍然是一个 MSE 意义上的收缩估计器，不是波动水平预报器。

## 8. 下一步

1. **分层抽样**：按交易所（沪/深/创业板）+ 市值分位重新抽样，检验 `000xxx` 结论是否外推。
2. **高波动区间的专门处理**：这是本次最明确的失效区域，进入阶段 B（水平项更新 / 分位数回归）时应优先在此评估。
3. **单股显著性**：把跨股票的中位数结论与单股推断分开表述，避免"对每只股票都有效"的误读。
