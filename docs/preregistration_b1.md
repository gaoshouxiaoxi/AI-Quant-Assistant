## 1. 研究问题

现有证据（3 只 / 25 只 / 63 只，三级独立预注册）表明：

- HAR-3 相对持续性基线的误差优势存在，但随样本代表性下降（+29% → +21.6% → +16.4%）
- 排序能力始终不如基线
- **失效集中在高波动股票**：63 只中 14 只负 Skill，其平均年化波动全部 ≥ 48%

**B1 只回答一个问题：**

> **在不改变 HAR-3 特征与系数估计方式的前提下，仅用一个滚动窗口估计的截距修正，
> 能否降低预测损失？**

副问题（预先声明的重点次要分析）：**该修正在高波动子集上是否更有效？**

---

## 2. 标签成熟时点（最先锁定）

现有 HAR-3 标签：

```
y_s = log( mean( RV[s+1 : s+5] ) )
```

即索引 `s` 的标签使用了 `s+1` 到 `s+5` 共 **5 个交易日**的 RV。

**成熟规则**：在预测起点 `t`，残差 `e_s = y_s − ŷ_s` 只有当

```
trading_day_index(t) − trading_day_index(s) ≥ 5
```

时才允许使用。

**实现约束（必须遵守）**：

- 交易日计数以**原始日线序列**（由 60 分钟 bar 聚合出的交易日，未经特征 NaN 过滤）为准，
  **不能**用日历日期加 5 天，也**不能**用特征数据集中的数组位置差。
- 若某交易日数据缺失，该日不进入计数；成熟条件按真实存在的交易日推进。

时间线（预测日 `t`）：

| 时点 | 状态 |
| --- | --- |
| `t` | 预测 `y_t`，残差 `e_t` **不可用** |
| `t+1 … t+4` | 未成熟 |
| `t+5` | `e_t` 成熟，此后可用于修正 |

---

## 3. 修正量定义

在预测日 `t`，可用残差集合：

```
E_t = { e_s : trading_day_index(t) − trading_day_index(s) ≥ 5 }
```

取其中最近的 **W = 20** 个：

```
δ̂_t = mean( Latest20(E_t) )
ŷ_t^B1 = ŷ_t + δ̂_t
```

**关键约束**：`ŷ_s` 必须是**当时真正产生的基础 HAR-3 预测**，不得事后用新模型重新拟合
或使用 B1 修正后的预测。残差始终定义为 `e_s = y_s − ŷ_s`（基础预测误差），
**不是** `y_s − ŷ_s^B1`。

若 `|E_t| < 20`，见 §6 失败规则。

---

## 4. 初始化：训练期**样本外**残差

### 4.1 为什么不用训练集内残差

若用"在整个训练折上拟合一次、再算训练集内残差"，这些预测参与了模型拟合，
残差会系统性偏小（OLS 的训练残差与真实预测误差不同）。滚动修正的目标是纠正
系统性偏差，初始值偏小会直接削弱 B1 的作用。

### 4.2 冻结的初始化流程

设外层折训练区间为 `Train = [0, b − purge)`，`b` 为该折测试起点。

1. 对训练区间内每个起点 `s`（从 `s = min_history_train` 开始），
   **只用 `[0, s − 5)` 的数据**拟合 HAR-3，得到 `ŷ_s`。
   —— 这是训练期内部的嵌套前向预测，`s − 5` 保证拟合样本的标签已经成熟。
2. 记录 `e_s = y_s − ŷ_s`，并记录其成熟时点 `trading_day_index(s) + 5`。
3. 在测试折起点 `b`，取训练区间内**已成熟**（`s + 5 ≤ b`）的残差，按时间排序，
   取最近 20 个，求均值作为初始 `δ̂_b`。
4. 若已成熟残差不足 20 个 → 该折判定为**协议失败**（见 §6），
   **不得**缩短窗口、不得借用测试期残差补足。

**冻结参数**：

| 参数 | 值 | 说明 |
| --- | --- | --- |
| `W` | **20** | 滚动窗口长度 |
| `horizon` | **5** | 标签前视窗口（决定成熟条件） |
| `min_history_train` | **60** | 训练期嵌套预测所需的最小训练样本数 |
| 嵌套拟合方式 | 扩展窗口，`[0, s−5)` | 与主实验的扩展窗口一致 |

`min_history_train = 60` 是**先验设定**（约 3 个月的日度样本，足够稳定估计 3 个系数），
不是根据结果调整的。

---

## 5. 测试折内逐日更新（顺序不可变）

对测试折内每个预测日 `t`，严格按以下顺序：

1. **生成基础预测**：用该外层折拟合好的 HAR-3 系数计算 `ŷ_t`。
   测试折内部**不重新估计** `rv_d / rv_w / rv_m` 的系数。
2. **选取可用残差**：筛出 `s + 5 ≤ t` 的残差，取最近 20 个，计算 `δ̂_t`。
   当日尚未成熟的标签不得参与。
3. **记录两种预测**：同时保存 `ŷ_t` 与 `ŷ_t^B1 = ŷ_t + δ̂_t`，保证两者测试日期完全一致。
4. **成熟后入队**：当日 `t` 的标签要等到 `t+5` 才成熟；成熟后计算 `e_t = y_t − ŷ_t`
   并加入残差历史，窗口只保留最新 20 个。

**注意**：第 4 步加入的是 `y_t − ŷ_t`（基础误差），不是 `y_t − ŷ_t^B1`。

---

## 6. 跨折状态隔离与失败规则

| 项 | 锁定规则 |
| --- | --- |
| 基础模型系数 | 每个外层折单独拟合；测试折内部固定不变 |
| 初始残差历史 | 仅来自**该折训练区间**内生成的、已成熟的历史样本外残差 |
| 测试期更新 | 仅使用**当前折**中已成熟的残差 |
| 窗口长度 | 始终为最近 20 个合格残差 |
| 测试折结束 | **清空**该折滚动状态 |
| 下一折开始 | 重新拟合基础模型，并从新训练折**重新构建**初始化残差历史 |
| 预测日期 | B1 与原始 HAR-3 使用**完全相同**的测试索引 |

**关于折间重叠**：下一折的训练区间可能包含上一折的部分测试日期。这些日期只有在
下一折训练时已成为可用历史、且标签已成熟时，才按 §4.2 的嵌套规则**重新生成**残差。
**不是**把上一折的滚动状态传递过去。

**失败规则**：

- 若某只股票在任意外层折的测试起点处，已成熟的训练期残差 < 20 个
  → 该股票标记为 `protocol_failure`，**不进入主指标**，数量与原因写入报告。
- 不允许缩短窗口、不允许用测试期残差初始化、不允许跳过该折。

## 7. 指标（运行前冻结）

### 主指标

> **63 只股票上 B1 的跨股票 Skill 中位数**

`Skill^B1_i = 1 − MSE(ŷ^B1_i) / MSE(rv_w_i)`，与既有实验完全同一基线、同一测试日期。

### 重点次要指标（预先声明）

1. **配对相对改善**：`Δ_i = 1 − MSE(ŷ^B1_i) / MSE(ŷ_i)`，
   报告跨股票中位数与 95% CI。这是与 HAR-3 的直接配对比较。
2. **高波动子集**：在 §7.3 定义的子集上，报告 B1 的中位 Skill、正占比、与 HAR-3 的配对 Δ。
3. 正 Skill 占比、离散度比、Spearman 与基线之差。

### 7.3 高波动分组的定义（禁止使用测试期信息）

分组必须只用**预测起点之前**可获取的信息：

- 对每只股票，取**第 1 折训练区间**（最早的 40% 交易日，且早于任何测试预测）
  的日度 RV，折算为年化波动率，求其中位数作为该股票的"历史波动水平"。
- 按 63 只股票的该指标取**横截面中位数**，分为"高波动组"与"低波动组"。
- 该分组在运行前一次性确定，写入配置文件，后续不得调整。

**禁止**用整个测试期的平均波动率分组（那是未来信息）。

### 7.4 区间估计

- **跨股票中位数**：以股票为聚类单位的 bootstrap（1000 次，取 2.5%/97.5%）。
- **单股票配对 Δ**：移动块 bootstrap（块长 10 个交易日，1000 次），
  处理 5 日重叠标签造成的自相关。
- **明确局限**：上述区间只刻画跨股票异质性与单股票时间依赖，
  **不修正股票间的共同因子暴露**。63 只不是 63 个独立证据。

## 8. 判断规则（运行前冻结）

| 结论 | 条件 |
| --- | --- |
| **B1 有效** | 配对相对改善的中位数 > 0 **且** 其 95% CI 下界 > 0 |
| **部分有效** | 中位数 > 0 但 CI 含 0 |
| **无效** | 中位数 ≤ 0 |

主指标（B1 的中位 Skill）用于**报告**，配对 Δ 用于**判定**——因为两者使用同一基线，
配对 Δ 直接回答"B1 是否优于 HAR-3"，不受基线选择影响。

高波动子集的结果作为**描述性**重点报告，若与整体结论不一致，必须同时呈现，不得只报有利的一方。

## 10. 结果解释的边界

- Skill 与 Δ 只反映**相对指定滞后基线的预测损失**改善，
  **不代表**收益率、投资收益或实盘盈利能力。
- 即便 B1 有效，也只说明"截距项存在可利用的漂移"，不说明波动可被准确预测。
- 单股票层面的结论必须与其 CI 一起呈现；多数单股 CI 可能包含 0。

---

## 11. 已知局限（事先承认）

1. 仍只有 2024-10 ~ 2026-10 一个市场环境。
2. `W = 20` 是任选值，本文不检验其敏感性（已明确不做）。
3. 截距修正假设偏差是**加性的、缓慢变化的**；若偏差随波动水平变化（异方差），
   该方法可能只在中低波动区有效。
4. 分钟线不复权，除权日污染 RV。
5. 嵌套历史预测会带来轻微的选择效应（`s` 必须 ≥ 60），影响方向未定。
