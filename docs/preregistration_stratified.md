## 0. 为什么做这个实验

前一个实验的 25 只股票**全部来自深市主板 `000xxx`**。这是"按代码升序取前 25"规则的
机械后果，不是刻意挑选，但确实**不知道结论能否推广到沪市主板、创业板与小市值股票**。

**本实验只回答一个问题：**

> **在按板块与市值分层后，HAR-3 的误差优势是否仍然存在？**

不修改模型、不修改评价协议、不重跑已有 25 只实验。

## 2. 分层方案（固定）

### 2.1 板块（3 层）

| 层 | 判定规则（代码前缀） |
| --- | --- |
| 沪市主板 | `600` / `601` / `603` / `605` |
| 深市主板 | `000` / `001` / `002` / `003` / `302` |
| 创业板 | `300` / `301` |

**科创板（`688`）不纳入本实验**，理由（属范围决定，与本实验结果无关）：

- 涨跌幅限制为 20%、投资者适当性门槛不同，波动结构不可直接与主板比较；
- 若混入，板块间差异会同时包含制度差异与选股差异，无法分离。

科创板留作后续独立研究（预注册时即声明，不是看到结果后排除）。

### 2.2 市值（3 层，用指数成分作代理）

| 层 | 代理指标 |
| --- | --- |
| 大市值 | 沪深300 成分股（`000300`） |
| 中市值 | 中证500 成分股（`000905`） |
| 小市值 | 中证1000 成分股（`000852`） |

选指数成分而非实时市值：**成分股名单是时点快照、可复现、且不受抓取当天行情影响**。

### 2.3 配额

- 共 **9 个格子**，每格 **7 只**，目标总数 **63 只**（满足"至少 60 只"）。
- 若某格通过数据检查的股票不足 7 只，则该格取满即可，并在报告中标注缺口；
  **不跨格借调**（跨格借调会破坏分层结构）。

### 2.4 抽样规则（可复现、与表现无关）

1. 每个格子内，候选股票按代码升序排列。
2. 用 **固定种子（42）的随机置换**打乱顺序，得到该格的抽取队列。
3. 依次检查数据完整性，取前 7 只合格者。
4. 置换种子与最终名单一并记录；任何人可用同一脚本重放出同一名单。

用随机置换而非"按代码升序取前 N"：后者在前一个实验中导致样本全部落在 `000xxx`，
随机置换可避免同类代码聚集。

### 2.5 与既有 25 只实验的关系

- 允许重叠（抽样是随机的，强行剔除会造成选择偏差）。
- 重叠数量与清单记录在 `reports/stratified/overlap_with_cross_stock.csv`。
- **不修改、不重跑**前一个实验的任何产物。

## 4. 模型与评价（与已审计协议完全一致）

- 模型：HAR-3（`rv_d`, `rv_w`, `rv_m`），OLS
- 基线：持续性（周均 RV）
- 目标：`log(mean(RV[t+1 : t+5]))`
- 切分：扩展窗口 5 折，`min_train_frac=0.4`，**purge = 5**
- 缺失：删除标签或任一特征缺失的行；模型与基线共用同一批日期
- 密度：60 分钟 bar；RV = `Σr² + 隔夜²`（不复权，除权污染用敏感性检验处理）

---

## 5. 指标

### 主要指标（唯一）

> **全部 63 只股票的跨股票 Skill 中位数**（不分子层）

### 次要指标（预先声明的分层分析）

1. **9 个格子各自的中位数 Skill、正 Skill 占比、n**
2. 按板块合并（3 个板块）与按市值合并（3 个层级）的中位数 Skill
3. Spearman 与基线之差（逐股票 + 中位数）
4. 离散度比（收缩程度）
5. 波动三档的系统性偏差
6. 时间二分稳定性

### 相关性说明（重要）

63 只股票**不是 63 个独立证据**。同板块、同市值层的股票高度相关。
因此：

- 主要指标的置信区间用**以股票为聚类单位的 bootstrap**，但该区间仅刻画
  "跨股票异质性"，**不**修正股票间的共同因子暴露。
- 分层结果的样本量小（每格 7 只），**只作描述性报告**，不做显著性检验，
  也不据此宣称"板块差异显著"。
- 若要做 9 个格子的正式比较，需 9 次检验的多重校正（Bonferroni α=0.0056），
  本实验**不做**，留待后续。

## 6. 判断规则（预先固定，与前一实验相同）

| 结论 | 条件 |
| --- | --- |
| **支持 H1** | 中位数 Skill > 0 且 95% CI 下界 > 0 且 正 Skill 占比 ≥ 70% |
| **部分支持** | 中位数 > 0 但（CI 含 0 或 正占比在 50%~70%） |
| **不支持** | 中位数 ≤ 0 |

**不满足"支持"时不得宣称误差优势可推广到分层后的股票群体。**

---

## 7. 置信区间

- 跨股票中位数：以股票为聚类单位、1000 次有放回重采样，取 2.5%/97.5% 分位。
- 单只股票：移动块 bootstrap，块长 10 个交易日，1000 次
  （标签为 5 日均值，误差自相关，独立重采样会低估方差）。

---

## 8. 预先声明的敏感性检验

1. **剔除隔夜前 1%**（防除权跳跃）
2. **时间二分**（前后半段各自的中位数 Skill）
3. **波动三档**（各档偏差与 Skill）
4. **基线改为当日 RV**
5. **剔除与前一个实验重叠的股票**后重算中位数（检验结论是否由重叠样本驱动）

## 11. 已知局限（事先承认）

1. 仍只有 2024-10 ~ 2026-10 一个市场环境。
2. 用指数成分代理市值，成分调整会带来轻微的时点偏差。
3. 每格仅 7 只，分层结论的统计功效很低。
4. 科创板不在范围内。
5. 分钟线不复权，除权日污染 RV。
