# B1 报告：滚动截距修正（负面结果 + 一处前序结论的纠正）

> 预注册见 [preregistration_b1.md](preregistration_b1.md)（commit `200f20e`，
> 在编写任何 B1 代码之前提交）。原始 HAR-3 代码与参考结果**未做任何修改**。
> 全部数字由 `python run_b1.py` 生成。

---

## 摘要

**B1 无效。** 在 63 只股票、完全相同的测试日期上，滚动截距修正使配对损失
中位数变差 **−7.45%**（95% CI [−12.36%, +1.09%]），仅 38% 的股票改善。

副产物（比主结果更重要）：**前一份报告中"高波动股票失效"的结论，
在改用事前可得的波动分组后不成立。** 见 §5。

## 1. 设计

| 项 | 设定 |
| --- | --- |
| 修正对象 | 只修正截距：`ŷ_t^B1 = ŷ_t + δ̂_t`，HAR-3 三个系数在测试折内冻结 |
| 窗口 | `W = 20` |
| 成熟规则 | `trading_day(t) − trading_day(s) ≥ 5`（交易日序号取自原始日线） |
| 初始化 | 训练期**样本外**嵌套预测残差中最近 20 个已成熟者 |
| 隔离 | 每折重新拟合、重新构建历史、折末清空状态 |
| 失败规则 | 任一折可用残差 < 20 → 协议失败，不缩窗口 |
| 验证 | 63 只，0 协议失败 |

**实现正确性证据**：B1 的基础路径与既有参考结果**逐位相同**
（`skill_base` 与 `reports/stratified/per_stock.csv` 最大绝对差 `0.000e+00`，n 全一致）。
所以下面的负结果不是实现错误的产物，有测试 `test_base_path_matches_reference_results` 守护。

## 2. 主结果

| 指标 | HAR-3 | B1 |
| --- | --- | --- |
| 跨股票 Skill 中位数 | **+16.43%** | +14.42% |
| Spearman 中位数 | 0.364 | 0.389 |
| 离散度比中位数 | 0.52 | **0.83** |

**配对比较（同一股票、同一日期）**：

| 统计量 | 值 |
| --- | --- |
| 配对相对改善中位数 | **−7.45%** |
| 95% CI（股票聚类 bootstrap） | **[−12.36%, +1.09%]** |
| 正改善股票占比 | **38.1%（24/63）** |
| 截距修正 δ̄ 中位数 | +0.158 |
| δ̄ 的标准差中位数 | 0.395 |

按预注册判定：配对中位数 ≤ 0 → **无效**。

## 3. 为什么无效：B1 是一个"水平拉平器"

诊断（后验，仅用于解释）：

| 关系 | Spearman |
| --- | --- |
| 基准 Skill 与配对改善 | **−0.735** |
| δ̄ 与配对改善 | +0.735 |
| 离散度比变化与配对改善 | −0.365 |

| 分组 | 基准 Skill 中位数 | δ̄ 中位数 |
| --- | --- | --- |
| B1 改善的 24 只 | **−1.50%** | +0.331 |
| B1 变差的 39 只 | **+24.18%** | +0.072 |

**读法**：B1 把每只股票的预测往一个共同水平推。

- 对本来就已经失效的股票（基准 Skill ≈ −1.5%），这个推动恰好补上了它的大偏差 → 改善
- 对本来表现良好的股票（基准 Skill ≈ +24%），它破坏了已经校准好的水平 → 变差

净效应为负，因为让一个**已经接近最优的收缩估计**偏离其水平，代价大于修正一个坏模型带来的收益。

这与 §4 的机理一致，也**反向支持**了"收缩是 MSE 最优"这一解释：
B1 把离散度比从 0.52 推到 0.83（更少收缩），同时 MSE 变差。

## 4. 高波动子集（事前分组）

分组规则按预注册执行：用**第 1 折训练区间**（最早的 40% 交易日，早于任何测试预测）
的日度 RV 折算年化波动，取横截面中位数切分（切点 26.0%）。

| 子集 | n | Skill HAR-3 | Skill B1 | 配对 Δ 中位 | 正改善占比 |
| --- | --- | --- | --- | --- | --- |
| 事前低波动 | 31 | +8.32% | +12.03% | **−3.16%** | 45% |
| 事前高波动 | 32 | +21.25% | +15.82% | **−11.65%** | 31% |

**假设被否定**：如果高波动失效源自"水平漂移"，那么修正截距应当在高波动子集上
**更**有效。实测相反——高波动子集变差得更多（−11.65% vs −3.16%）。

**结论：高波动股票的失效不是简单可加的截距漂移。**

## 5. 一处前序结论的纠正（重要）

前一阶段（[stratified_report.md](stratified_report.md) §4）基于"整段样本外平均波动"
把股票分为高/低波动组，得出"高波动股票 Skill 更差"。**那个分组变量使用了未来信息。**

B1 的预注册要求分组只能用预测起点之前的信息，因此这里改用第 1 折训练期波动重新分组，
结果如下：

| 分组方式 | 分组变量可得时点 | 高波动组 Skill | 低波动组 Skill | 结论 |
| --- | --- | --- | --- | --- |
| **事后**（前一报告） | 用了整个样本外区间 | 0.022 | 0.257 | 高波动更差 |
| **事前**（本报告） | 预测起点之前 | **0.212** | 0.083 | **高波动更好** |

两个分组变量的秩相关只有 **0.378**——它们衡量的根本不是同一件事。

**必须修正的表述**：

- ❌ 原："高波动股票上 HAR 失效（14 只负 Skill 全部 ≥48% 波动）"
  这是**事后条件描述**：它描述的是"在已经知道结果的样本里，误差较大的那些股票恰好波动高"，
  不是一条可用于选股或风控的事前规则。
- ✅ 应改为："在本样本中，样本外已实现波动较高的股票，HAR 的 Skill 更低。
  但该关系依赖于事后分组，用事前波动分组时方向反转，因此**不能作为可部署结论**。"

**仍然成立的**：
- 高波动**区间**（同一只股票内部、按当期已实现波动分档）内，模型偏差为负、
  Skill 为负——这一条是"条件于当期已实现波动"的误差描述，作为诊断成立，
  但同样需要 `actual_vol`（未来 5 日目标）才能分组，**同样不是事前可用的规则**。
- 收缩现象、排序不如基线、多因子无增量——这些不依赖分组，不受影响。

## 6. 这次实验真正暴露的方法论问题

**用结果变量分组，会系统性地产生"某类股票失效"的假象。**

本项目此前多处按"真实波动"分档（`diagnostics_har.py`、`run_sensitivity`）。
这些分析的定位应当明确为：**误差诊断（error diagnosis）**，
回答"错误集中在哪里"，而**不是**"哪些股票不能预测"。
后一个问题必须用事前分组回答，而本报告显示两者结论相反。

建议在后续所有分层/分档分析中标注分组变量的信息时点（事前 / 当期 / 事后）。

## 7. 局限

1. `W = 20` 未做敏感性检验（预注册明确不做）。
2. 只测了"加性截距修正"这一种形式，未测斜率修正、分位数回归。
3. 仍只有 2024-10 ~ 2026-10 一个市场环境。
4. 事前分组用第 1 折训练期波动，样本较短（约 280 个交易日的前 40%）。
5. 配对 bootstrap 只处理单股票时间依赖，未处理股票间共同因子。

---

## 8. 结论与下一步

**B1 应被放弃**：截距修正无法改善预测损失，且在高波动子集上更差。

**下一步的三个候选**（按本报告证据排序）：

1. **不做水平修正，改做"条件收缩"**：既然收缩是 MSE 最优的，问题不是"要不要收缩"，
   而是"收缩强度是否应随波动水平变化"。可试在训练折内估计最优收缩系数（shrinkage
   intensity），而不是加常数。
2. **分位数回归**：目标从"均值"改为"高分位"，直接回答"波动会不会很大"，
   而不是"平均波动是多少"。这与已观测到的均值低估方向一致。
3. **承认当前边界**：在只有一个市场环境、约 280 个样本外交易日的前提下，
   任何"改善高波动预测"的尝试都可能是过拟合。若要继续，优先扩时间范围而非加模型。
