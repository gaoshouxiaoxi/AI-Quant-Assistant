> **本文件在抓取任何新股票行情数据之前写定并提交。**
> 后续分析不得修改本文件中的选择规则、主要指标与判断门槛；
> 任何偏离都必须作为"事后分析"单独标注，不计入主结论。

- 预注册日期：2026-10-18
- 基线代码版本：`main` @ `710f614`
- 分支：`research/cross-stock-validation`
- 协议文件：`configs/cross_stock.json`（哈希记录在 `reports/cross_stock/preregistration.json`）

## 1. 研究问题

主实验在 3 只股票上得到：HAR-3 相对持续性基线的 Skill 平均 +28.45%，
但排序能力低于基线，且预测存在强收缩。

**本实验只回答一个问题：**

> **原有的误差优势（Skill > 0）能否在更广泛的股票样本中重现？**

**不改变**任何既有设定：目标定义、HAR-3 特征、基线、purging、主评价指标全部沿用主实验。

---

## 2. 股票选择规则（可机械执行，与表现无关）

1. **股票池**：沪深 300 成分股快照，来源为中证指数官网（经 akshare
   `index_stock_cons_csindex("000300")` 获取），快照日期 **2026-10-16**，共 300 只。
2. **只保留 A 股**（交易所为上海证券交易所或深圳证券交易所）。
3. **按股票代码字符串升序排序**（`000001` → `000002` → … → `600xxx`）。
   —— 代码顺序与公司质量、历史表现无关，仅用于确定性地抽取样本。
4. **依次抓取 60 分钟 bar**（新浪 `datalen=1970`），保留同时满足以下条件的：
   - bar 数 ≥ **1900**（理论最大 1970，允许约 3.5% 缺失）
   - 首个 bar 不晚于 **2024-10-10**
   - 最后一个 bar 不早于 **2026-10-09**
   - 每个交易日 bar 数的**中位数 = 4**（排除长期半天交易或结构性缺失）
5. 取**前 25 只**通过筛选的股票作为研究样本。
6. **排除即记录**：任何被排除的股票与原因写入 `reports/cross_stock/universe_exclusions.csv`。
   **不允许因结果不好而替换样本。**
7. 被排除的候选按规则**顺延**，不跳号、不挑选。

## 3. 数据与口径

| 项 | 设定（与主实验一致） |
| --- | --- |
| 频率 | 60 分钟 bar，每日理论 4 根 |
| 复权 | 新浪分钟线为**不复权**价格；除权日会产生跳跃，见 §7 敏感性检验 |
| 交易日历 | 各股票自身的 bar 日期为准；缺失日不补，直接跳过 |
| 日度 RV | `Σ r_i² + 隔夜收益²`（日度方差，未年化） |
| 标签 | `log(mean(RV[t+1 : t+5]))` |
| 缺失处理 | 删除标签或任一特征缺失的行 |
| 样本对齐 | 全部特征并集无缺失的日期；模型与基线共用同一批日期 |

**统一性说明**：所有股票使用同一接口、同一 `datalen`、同一解析路径、同一特征代码，
差异只来自股票本身。

## 4. 模型与切分（与主实验完全一致）

- 模型：HAR-3（`rv_d`, `rv_w`, `rv_m`），OLS
- 基线：持续性（周均 RV，即 `rv_w` 直接外推）
- 切分：扩展窗口前向验证，5 折，初始训练占比 0.4，**purge = 5 行**
- 随机种子：42（本实验无随机模型）

---

## 5. 评价指标

### 主要指标（唯一，预先指定）

> **跨股票 Skill 的中位数**

`Skill_i = 1 − MSE_model,i / MSE_baseline,i`，其中 MSE 在样本外区间计算。

**为什么取中位数**：25 只股票的 Skill 分布可能右偏，均值会被个别高值拉动；
中位数对离群值稳健，且能回答"典型股票上是否有效"。

### 次要指标（全部报告，不单独用于下结论）

| 维度 | 内容 |
| --- | --- |
| 误差表现 | 逐股票 Skill、MAE（模型与基线） |
| 跨股票稳健性 | Skill 中位数、正 Skill 股票占比、四分位距、分布直方图 |
| 排序能力 | Spearman 与基线之差（逐股票 + 中位数） |
| 时间稳定性 | 样本外区间二分为前后半段，分别计算中位数 Skill |
| 估计偏差 | 按真实波动三分位，各档的平均偏差（log 空间） |
| 逐股票明细 | 全部 25 只的完整表格，不只报总体 |

## 6. 判断规则（预先固定）

对主要指标 **跨股票 Skill 中位数（M）** 及其 95% 置信区间：

| 结论 | 条件 |
| --- | --- |
| **支持 H1** | M > 0 **且** CI 下界 > 0 **且** 正 Skill 股票占比 ≥ 70% |
| **部分支持** | M > 0 但（CI 含 0 **或** 正占比在 50%~70% 之间） |
| **不支持** | M ≤ 0 |

**不满足"支持"时不得宣称误差优势可推广。** 若结果落在"部分支持"或"不支持"，
如实报告，不通过换指标、换阈值、换样本挽回。

---

## 7. 置信区间构造（考虑时间依赖）

1. **跨股票中位数 M 的 95% CI**：对 25 只股票做 **1000 次有放回重采样**（cluster bootstrap，
   以股票为聚类单位），取 2.5% 与 97.5% 分位数。这样处理了股票间的异质性，
   但**不**处理单只股票内部的时间依赖。
2. **单只股票 Skill 的 95% CI**：**移动块 bootstrap**，块长 **10 个交易日**，重复 1000 次。
   之所以用块而非独立重采样：标签是 5 日均值，误差序列存在自相关，
   独立重采样会低估方差。

---

## 8. 预先声明的稳健性检验

以下检验在**看结果之前**确定，结果无论好坏都报告：

1. **除权跳跃敏感性**：剔除隔夜绝对收益处于该股票前 1% 的交易日，重算中位数 Skill。
   （新浪分钟线不复权，除权日会制造假跳跃。）
2. **时间稳定性**：样本外区间二分为前后半段，分别计算中位数 Skill 与正 Skill 占比。
3. **波动分档**：按真实波动三分位分组，报告各档平均偏差与 Skill。
4. **基线替换**：把"周均 RV"换成"当日 RV"作基线，看 Skill 中位数是否仍为正
   （用于确认结论不依赖于基线的选择）。

## 11. 已知局限（事先承认）

1. 样本仍是 2024-10 ~ 2026-10 的单一市场环境，跨 regime 的外推仍然有限。
2. 25 只股票均来自沪深 300，偏向大市值，结论不能直接推广到小盘股。
3. 分钟线不复权，除权日会污染 RV；已设敏感性检验，但不能完全消除。
4. 60 分钟每日 4 根 bar，RV 精度有限，无法分离跳跃成分。
