# AI Quant Assistant

An AI-powered quantitative analysis platform.

## Features

- Stock data collection
- Technical analysis
- Backtesting
- Machine learning prediction

## Tech Stack

- Python
- Pandas
- Machine Learning
- Streamlit

## Getting Started

```bash
pip install -r requirements.txt
```
